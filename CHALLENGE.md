# Simple Money: sastranet Development Challenge

Welcome! **Simple Money** is a small expense tracker built with plain HTML, CSS and JavaScript.
Your job is to explore it, find out what's wrong with it, and then make it your own.

You can find the full challenge details in [`sastranet_DC_handout_2k26.pdf`](sastranet_DC_handout_2k26.pdf).

- **Duration:** 50–60 minutes
- **Format:** individual challenge

## Getting started
1. Fork this repository, then clone your fork to your computer.
2. Create your own branch: `git checkout -b <your-name>/dc`
3. Open the folder in VS Code and install the **Live Server** extension.
4. Open `index.html` and click **Go Live** to run the site in your browser.

## What the app is supposed to do
- Add an expense with a description, amount, category and date
- Show all expenses with their category and date
- Show how many expenses there are and the total amount
- Filter the list by category
- Delete a single expense, or clear all of them
- Remember your expenses after you refresh the page

## The four tasks

### Task 1: Bug Finding (no AI allowed)
The app has **several bugs**. Some are easy to spot and some are well hidden.
Use the app the way a real user would: try every button, every filter, and odd inputs, and refresh the page.

Write each bug you find in a `BUGS.md` file:
- What you did
- What you expected to happen
- What actually happened

Finding more bugs, and especially the hidden ones, earns you more points.

> Tip: the browser's Developer Tools (`F12` → **Console**) are your best friend.

### Task 2: Bug Fixing (AI allowed)
Fix as many of the bugs you found as you can. For each fix, add a short note in `BUGS.md` saying where
the problem was and how you fixed it.

### Task 3: Feature Development
Add a **new feature** or meaningfully improve an existing one. Pick something that makes the app more
useful for someone tracking their money. Simply changing a label or adding one extra category doesn't
count. Show us your own idea and think it through.

### Task 4: Creative Redesign
The app works, but it looks very plain on purpose. Redesign it to make it attractive, easy to use and
visually engaging. How you do it is up to you.
